# AWS deployment student kit

Start with STUDENT-GUIDE.pdf, STUDENT-GUIDE.html or [STUDENT-GUIDE.md](STUDENT-GUIDE.md).
They follow the CloudShell, CodeBuild, ECR and ECS Fargate workflow in the video.

Configure your own AWS account before preflight. This kit uses Stockholm (eu-north-1).
The student guide includes setup, commands, expected results, browser exercises,
resuming a session and cleanup. See IAM-REQUIREMENTS.md, TROUBLESHOOTING.md and
VIDEO-CHAPTERS.txt for additional help.

The source archive includes the application and existing course media. It excludes
instructor credentials, deployment state, recorded evidence and the MP4. Paid model
execution is disabled. Server storage is ephemeral; CloudFront provides browser
HTTPS with an HTTP connection to the load balancer origin.
