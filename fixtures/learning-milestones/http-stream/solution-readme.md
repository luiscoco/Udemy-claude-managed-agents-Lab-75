# Local streaming tutor reference

This optional reference contains a completed starter.ts. Extract it into a new folder to preserve your own work. Requires Node 24 or newer; no dependency installation or provider credentials are needed. The tests use loopback networking only.

Open this http-stream folder and run:

```powershell
node --test starter.test.mjs
```

Expected: 3 tests passed, 0 failed. The tests start and stop their own local HTTP server. Read WALKTHROUGH.md. This deterministic tutor does not call a model and is not a production server.
