# Build the complete learning experience

Open one prompt at a time in this order. A lettered lesson extension belongs immediately after its parent lesson. Do not skip its checkpoint.

- [P01 Unify the visual design](steps/P01.md) — Give every lesson the same readable and responsive workspace.
- [P02 Author the seven section Learning Guide](steps/P02.md) — Create one teaching catalog for visible explanations and narration.
- [P03 Implement written guided tours and highlights](steps/P03.md) — Connect the guide to real mounted content without running exercises.
- [P04 Add explicit author only Inworld synthesis](steps/P04.md) — Provide bounded recording tools while keeping student playback key free.
- [P05 Package all lesson recordings and manifests](steps/P05.md) — Ship 525 verified MP3s instead of requiring student API keys.
- [P06 Synchronize narration to the exact spoken paragraph](steps/P06.md) — Prevent the whole section highlight bug after a spoken fragment.
- [P07 Add progress notebooks bookmarks and backups](steps/P07.md) — Save optional browser-local learning state with safe restoration.
- [P08 Add knowledge checks learning paths and review](steps/P08.md) — Offer concept practice separately from self-assessment and execution.
- [P09 Build the three offline milestone starters](steps/P09.md) — Supply small downloadable projects students run on their own machines.
- [P10 Add milestone solutions and readable experiment results](steps/P10.md) — Help students understand failures and inspect evidence without chat assistance.
- [P11 Add durable shortcuts to every learning tool](steps/P11.md) — Make notebooks exercises progress and backups directly discoverable.
- [P12 Add Start here and truthful validation records](steps/P12.md) — Orient students and show evidence scoped to tested commits.
- [P13 Audit the interface of all 75 lessons](steps/P13.md) — Check every real view rather than relying on a few screenshots.
- [P14 Define both illustrated tours for every lesson](steps/P14.md) — Create 150 source-grounded infographic plans and 900 region explanations.
- [P15 Generate the 150 original infographic images](steps/P15.md) — Use the supplied per-image prompts with different astronaut poses.
- [P16 Review and correct every infographic](steps/P16.md) — Catch visual claims that contradict the implementation.
- [P17 Measure regions and bind image identities](steps/P17.md) — Make red rectangles fit the actual reviewed panels.
- [P18 Record or reuse the visual narrations](steps/P18.md) — Supply 150 prerecorded tours with real six-region timings.
- [P19 Build the illustrated player zoom and pan](steps/P19.md) — Make the two visual tabs usable with synchronized region navigation.
- [P20 Narrate the main TypeScript concept in every lab](steps/P20.md) — Synchronize source-specific Inworld MP3 explanations with precise source line rectangles.
- [P21 Add accessible code reading controls](steps/P21.md) — Adjust font size, wrapping and full-screen reading while preserving timed source highlights.
