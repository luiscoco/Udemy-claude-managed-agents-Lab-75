# Build lessons 16 through 30

Open one prompt at a time in this order. A lettered lesson extension belongs immediately after its parent lesson. Do not skip its checkpoint.

- [L16 Environment and configuration provenance](lessons/L16.md) — Trace synthetic host configuration precedence, server credential readiness and explicit Managed environment resources without conflating their scopes.
- [L17 Host snapshots and file restoration](lessons/L17.md) — Restore tracked host fixture files from an owned snapshot while the retained Managed conversation remains intact.
- [L18 Cloud sandbox and host boundaries](lessons/L18.md) — Inspect configured cloud sandbox policy and independently test a disposable host file boundary without conflating either with agent permission flags.
- [L19 Session inventory and explicit branches](lessons/L19.md) — Inventory owned Managed sessions, inspect bounded history pages and derive a fresh conversation from an explicit host summary.
- [L20 Lifecycle events and host interceptors](lessons/L20.md) — Correlate Managed lifecycle events with host interceptor decisions and actual custom-tool effects without treating observations as SDK hook callbacks.
- [L21 Host commands and prompt expansion](lessons/L21.md) — Validate host commands, inspect exact fixed-template expansion, and distinguish local-only actions from messages sent on an owned session.
- [L22 Explicit project context and memory](lessons/L22.md) — Trace exactly which authored project and summary files the host selects for a fresh Managed session without assuming automatic CLAUDE.md discovery.
- [L23 Reusable capability bundles](lessons/L23.md) — Compose a reviewed, hash-pinned host bundle of commands, tools, skills, agent definitions and optional MCP declarations while enforcing worker least privilege.
- [L24 Who owns the agent loop](lessons/L24.md) — Compare who iterates, executes host tools, holds state and cleans up in a manual Messages loop, the Messages SDK tool runner and Managed session custom tools.
- [L25 Context growth and compaction evidence](lessons/L25.md) — Distinguish observed Managed compaction events, available cumulative thread usage and a separate host-authored summary handoff without inventing context capacity.
- [L26 Session controls and supported updates](lessons/L26.md) — Operate an owned session through a strict catalog and compare updates that require idle with an explicit fresh-session model handoff.
- [L27 Remote work beyond a browser connection](lessons/L27.md) — Track authored remote work in a host ledger across browser detach and reconnect without creating duplicate sessions or task cards.
- [L28 Errors retries and reconciliation](lessons/L28.md) — Classify authored transport, event, handler and cleanup faults while bounding read retries and reconciling uncertain mutations without duplicate effects.
- [L29 Images documents and mounted files](lessons/L29.md) — Compare checked inline image/document blocks, explicit file mounts and separate downloaded output evidence using small fictional fixtures.
- [L30 Host task board and completion gates](lessons/L30.md) — Use a host-owned task board and typed custom-tool inputs to enforce dependencies, versions and checked completion evidence independently of agent claims.
