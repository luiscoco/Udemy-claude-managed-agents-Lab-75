# Small student pilot before Udemy release

Status: prepared; no participants recruited and no results recorded.

Invite 3-5 volunteers yourself, including a beginner, someone comfortable with TypeScript and a phone user. Supply the same sanitized source ZIP and prompt ZIP intended for Udemy. Ask participants to keep API keys and personal data out of feedback. Start with offline fixtures and included recordings; no paid services are required.

## Tasks, approximately 25 minutes

1. Follow the clean-install instructions, start the app and locate Start here. Record operating system, browser, setup time and any unclear instruction.
2. Open Lab 01, describe its objective, run the offline example and identify one lifecycle event and its outcome.
3. Open the main TypeScript concept, play its code tour and explain one validation branch. Check whether the red rectangle and vertical follow make the spoken explanation easy to locate.
4. Change code font size and wrapping. Enter full-screen reading, pause/resume and move to another explanation. Exit with Escape or the visible button. Repeat the reading task on a phone or narrow window when available.
5. Save one lesson note, complete a self-assessment and download a learning backup. Restore only after reviewing its preview. Check that the note is retained.
6. Open the infographic tour and then return to source. Report any overlapping controls, clipped titles, unexpected audio or loss of position.

## Feedback record

For each issue record task number, expected behavior, observed behavior, exact reproduction steps, browser/window size and optional screenshot. Rate ease of setup, navigation, code readability and narration synchronization from 1 (difficult) to 5 (easy). Ask: What was confusing? What would you change first? Could you finish without instructor help?

Keep results in a separate instructor-owned feedback document. Do not ship volunteer identities or their learning backups in the course package. Fix reproducible blockers, repeat their exact steps and record the tested build and package hash before release. A completed technical regression is not a substitute for this student pilot.
