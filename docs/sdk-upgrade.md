# Upgrade the Anthropic TypeScript SDK

Current baseline: **@anthropic-ai/sdk 1.3.0**, the npm latest stable tag verified on **26 October 2026**, upgraded from 0.133.0. Pin the exact version in package.json and commit the npm lockfile. Node 24 or newer remains required. Historical checkpoint reports and frozen reference inputs describe their original versions; this migration supersedes those versions for current student builds. The separate Python and AWS SDK packages are not upgraded by this step.

## Student steps

1. Stop the development servers and preserve your working changes. Run these commands in the directory containing this app's package.json, not docs/ or the Python virtual environment folder. If npm is not recognized, install/activate Node 24 and open a new terminal first.
2. Check the current registry: `npm view @anthropic-ai/sdk dist-tags --json`. At this checkpoint latest is 1.3.0; do not silently float to an unreviewed release during replay.
3. Run `npm install --save-exact @anthropic-ai/sdk@1.3.0`. Keep both package.json and package-lock.json. Run `npm ls @anthropic-ai/sdk` to verify the direct dependency; a separate AWS adapter may retain its own nested SDK.
4. Inspect installed types and the official changelog. SDK 1.x defaults anthropic-version to **2026-10-21**. The SDK sends the API key as `Authorization: Bearer ...`; let it construct authentication rather than manually copying a secret into a header. Beta route selection no longer adds `beta=true`; retain **managed-agents-2026-04-01** in the beta header. Agent version remains an actual query parameter. Preserve stream-before-send, bounded inputs, actual event unions and resource ownership.
5. In the shared Anthropic client, preserve **maxRetries:0**, bounded timeout and logging redaction. Set **openTelemetry:{propagation:false,traces:{enabled:false}}** to keep SDK automatic instrumentation/propagation disabled; existing explicit host tracing is separate. Do not enable prompt-content telemetry implicitly.
6. Update current readiness/version metadata and Lab 55's installed baseline where applicable. Update intercepted-fetch tests to assert actual authentication/API/beta headers and routes. Verify no duplicate session/message/result submission, bounded cancellation, error redaction and billing diagnostics. Do not weaken tests or replace SDK declarations with casts to conceal incompatibility.
7. Run strict typecheck, the entire offline suite, browser checks, production build, distribution scan and relevant guide/media/prompt audits. Run lifecycle/browser servers sequentially to avoid port and cold-start interference. Regenerate the current student prompt package and verify its exact hashes. Use `npm ci` for a reproducible installation from the updated lockfile.
8. Restart with `npm run dev`. Local readiness checks installed compatibility; successful builds do not establish paid provider acceptance. This upgrade does not fix an API balance or organization mismatch. Preserve .env/.env.author privately. Provisioning, live model sessions and narration synthesis are separate explicit actions, never part of these upgrade checks.
