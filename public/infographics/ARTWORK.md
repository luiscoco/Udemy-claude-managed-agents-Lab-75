# Pilot artwork provenance

Six original illustrated PNGs were created for the Managed Agents implementation using the **built-in image generation tool**, not the CLI fallback. This pilot adapts the visual-tab pattern from `luiscoco/Udemy-Claude-Agent-SDK-Learning-Platform-v2`; its Agent SDK images were not copied into these Managed Agents lessons.

Final assets: `lab-01-concepts.png`, `lab-01-lab.png`, `lab-12-concepts.png`, `lab-12-lab.png`, `lab-65-concepts.png`, `lab-65-lab.png`. Each image is 1536 × 1024. The six generation prompts and two targeted Lab 01 corrections are in `prompts/`. All six final images were visually reviewed for their numbered regions, readable copy and alignment with the local teaching implementation. This is editorial review, not a claim of OCR or semantic certification.

The concept artwork was checked against session-event reconciliation and lifecycle outcomes, the Lab 12 queue and port contract, and the Lab 65 immutable proposal/reviewer/SQLite ledger boundary. The Lab 01 concept edit removed an inappropriate Agent SDK label and corrected the small session metadata list. Its walkthrough edit corrected the illustrated Run button caption to the actual control label and clarified the offline header badge.

The final measured region boxes live in `shared/learning-infographics.ts`; they do not assume that image generation followed the originally requested grid exactly. `pilot-manifest.json` binds each final image hash and dimensions to the catalog content hash and its matching Inworld MP3/timing files. Audio narration uses authored explanatory text, not OCR of the image. Full text remains available in the app.

All images are illustrated teaching summaries. They do not prove a model call, remote session, external notification, human decision or effect took place. Actual exercise evidence is separate.
